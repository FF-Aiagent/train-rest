## Description

```
Train / Rest helps serious runners answer one question: should you train, go easy, or rest today?

It reads your recent running load, sleep, and heart-rate variability from Apple Health when you allow it, then shows a plain-language call with a few short reasons. Missing data? You’ll see what was missing—no fake certainty.

Optional Pro ($4.99 one-time) unlocks a photo-based sore-spot log and a calendar of past calls. Your daily Train / Easy / Rest call stays free.

Train / Rest is a training preference helper, not a medical device. It does not diagnose, treat, or prevent any condition.
```
